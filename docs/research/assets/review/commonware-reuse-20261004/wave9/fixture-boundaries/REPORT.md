## Reuse actual runtime facilities without changing their meaning

## Actual chain reference: Alto replay without fresh network traffic

Alto's `chain/src/lib.rs` contains a cfg(test) full chain assembly and `test_drainer_replays_inflight_uploads_after_restart`. The first run starts actual validator assemblies over simulated links, blocks indexer uploads in flight, and retains a runtime checkpoint. The second run rebuilds the same validator registrations without relinking peers, then checks replayed uploaded digests and drained durable-queue metrics. This is a concrete two-run source pattern for future lost-completion/recovery scenarios, instead of inventing another crash simulator. It is not an executed result here or a Baton state-import proof. [Private chain test module](https://github.com/commonwarexyz/alto/blob/1d87569348b5560699465a72d691d90f18affb9c/chain/src/lib.rs#L198), [Replay test](https://github.com/commonwarexyz/alto/blob/1d87569348b5560699465a72d691d90f18affb9c/chain/src/lib.rs#L1317), [Recovery without relinking](https://github.com/commonwarexyz/alto/blob/1d87569348b5560699465a72d691d90f18affb9c/chain/src/lib.rs#L1487).
