The combined 35-file manifest and independent trees are retained here. This review inspects actual public boundaries and implementation arms, not merely the author's inventory.

- Public buffer construction/start uses raw registered channels and wraps them with the chosen body codec. WrappedReceiver L111–129 decodes complete frames and returns transport identity separately; buffer receive L207–225 logs/drops decode failures. It performs no application body/context/custody validation or blocker call for this decode path.
- Buffer L279–365 computes body digest, responds to existing waiters before checking latest-primary residency, and deduplicates resident content with per-peer deque/global digest counts. Same-peer duplicate refreshes position; different-peer reference shares cached content. Eviction drops the cache's Arc only after the last resident reference. Broadcast is a separate explicit mailbox arm. The report correctly separates delivery, transient memory retention, sending and native header/canonical identity.
- Public `subscribe(digest)` is local cache-hit-or-wait, not remote fetch or an all-incoming stream. The Engine serializes cache check and waiter registration. Returned Arcs keep material alive outside cache lifetime but give no archive durability. Closed receiver cleanup and get(None) on cache miss/shutdown are accurate; readiness and byte/waiter/overflow limits remain open.
- Generic resolver L405–423 correlates peer/request id then delivers expected key/subscribers + Bytes through Consumer without blocking the main loop. It does not know or inject the broadcast cache. Complete may locally redeliver an accepted response to later subscribers; Ambiguous retries valid wire data, initially Invalid blocks/retries, and Ignored retires the entire key. Already-accepted local-redelivery Invalid is a consumer-conflict case that does not penalize the original peer. The report's wording limits peer-invalid behavior to an initially invalid response and retains the existing body-page distinction.
- Tempo/Alto start the existing buffer and pass its mailbox into Standard Marshal; Alto does so before consensus. Standard Buffer forwards known digest subscriptions. Private Marshal Subscriptions/handler/actor code handles local lookup and caller-specific resolver fallback; Inline registers a local candidate wait before the certification gate. No private framework is offered as an importable native receive API, and its Simplex certification-dependent fetch policy is not adopted for native Automaton.
- Marshal subscription notification occurs before persistence and explicitly promises no durability, whereas finalized application dispatch is its separate archive-durable route. This reinforces the buffer/subscription versus custody boundary, without adding a readiness/ACK approval barrier.

The single-paragraph proposed reader addition is accurate and useful: use existing subscription for local arrival, then exact header/parent/application/custody checks; resolver Consumer can hand verified material directly to the same existing owner. No polling cache, automatic receive-triggered rebroadcast, buffer-injection method, generic incoming stream, extra actor/trait or selected fetch/custody policy is introduced.
