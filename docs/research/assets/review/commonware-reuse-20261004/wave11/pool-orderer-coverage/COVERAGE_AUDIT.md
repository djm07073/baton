## Fresh checks at the uncertain source boundaries

Twenty-four newly fetched raw primary files match Git blobs in five newly fetched authenticated complete pinned trees. The receipt binds their Git blobs, SHA-256 bytes and all reviewed page/diagram hashes. This is a focused check of the exact current boundaries, not a new generic API catalog.

Nunchi genuinely owns state in one task and exposes a public constructor/start/P2P start/handle. Pending selection clones contiguous nonce runs; canonical notification uses `try_send`. Its kernel updates nonce snapshots and runs height/TTL, so reliable processing/hydration is meaningful integration rather than another pool. Reth's public predicate calls iterator invalidation; Constantinople's batch selection pops its queue. Those differences justify the current conditional method recipe and open lifecycle cells.
