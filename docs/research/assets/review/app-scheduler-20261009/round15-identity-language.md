## Outcome and applied clarification

No incorrect equivalence remained in the reviewed contracts. The glossary already separated body digest, header digest and structured BlockRef, but its coordinate paragraph named only the canonical output index. I added one source-linked sentence at `docs/overview/glossary.md:43` distinguishing native View (consensus attempts within an epoch), producer height (one lane), and OutputIndex (the finalized output stream). This answers the likely same-integer/different-coordinate confusion without adding rows for temporary App bookkeeping.

The links point to the actual View documentation and OutputIndex documentation, the latter explicitly distinguishing producer height and declaring index zero to be the never-delivered genesis. The change adopts no new identity format or transaction policy.

The native fault model also has a DA quorum of n-2f, a nullification quorum of 2f+1 and a safe rank of f+1 (`utils/src/faults.rs:98–158` and the adjacent `da_quorum` definition). These are native message/rank rules, not substitutes for Baton intention support or the App result threshold. The current diagrams correctly say “native threshold” for DA rather than labelling every native certificate 4f+1. The BLS sharing validation actually calls `N5f1::da_quorum` and `nullification_quorum` (`scheme/bls12381_threshold/mod.rs:502–505`). No documentation change was required for this distinction.
