## Source-fit checks, not an invented assembly guarantee

The decisive retained source remains consistent with these explanations. Nunchi pending clones nonce runs; finalized uses try_send and Pool::finalize also changes height/TTL. Reth's public predicate delegates rejected items to dependency exclusion and its canonical update carries account/tip/outcome state. Constantinople pops whole batches, respects remaining signed-tx bytes and stops at an oversized lane head. These are concrete selection/lifecycle differences requiring an adapter around one chosen owner, not evidence that any backend can accept opaque Baton bytes unchanged.

Native header metadata binds producer coordinates/parent/body commitment. Running::inspect provides diagnostics and serve returns retained useful proof, not arbitrary exact historic source versions. DurableState stores native safety/outbox/forwarded exits while its ordering snapshot payload is empty; replay clears newly-ready observations. Existing Exact provides a local completion pattern without carrying application durable receipt material. These checked boundaries justify the current distinction between primitive reuse and the native exact-source/dense-delivery bridge.
