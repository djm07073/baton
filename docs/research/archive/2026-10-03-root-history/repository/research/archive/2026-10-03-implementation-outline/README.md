# 이전 구현 문서 snapshot

2026-10-03에 현재 구현 개요를 [IMPLEMENTATION_SPEC.md](../../../IMPLEMENTATION_SPEC.md) 한 파일로 정리했다. 이 폴더는 이전 상세 계약과 당시 논문의 원문을 byte 그대로 보존한다. 여기의 현재/latest 표현은 당시 snapshot의 설명이며 현재 구현 범위를 대신하지 않는다.

- [이전 구현 계약](baton-implementation-spec.md)
- [동반 논문 snapshot](baton-paper.md)

논문 snapshot에는 이 작업 전 존재하던 direction-no-reply 문서 변경도 포함한다. Google Docs를 새로 수정하거나 자동 동기화하지 않았다.

이전 진입 문서도 [README.previous.md](README.previous.md)에 원문으로 보존했다. 이 snapshot의 과거 상대경로·current 표현은 당시 자료의 일부이며, 현재 개발 진입점은 위 단일 구현 문서다.
